# ZapDMR 1.5.4

Distribuição oficial para Android e Windows, autorizada pelo responsável.

- Android: Modo Carro opcional, PTT por dois toques com opção de segurar/soltar, ganho TX de referência 260% (0–300%), VOX experimental indisponível e ajustes separados da rota de áudio MyLink.
- Cadastro por código temporário e perfil XLX026 recomendado, preservando os dados e a senha pessoal BrandMeister.
- Windows mantém a interface normal e os perfis independentes.
- Atualizadores existentes preservados. Instale por cima, sem desinstalar.

Os arquivos **ZapDMR-Android-1.5.4-source.zip** e **ZapDMR-Windows-1.5.4-source.zip**, anexados à release v1.5.4, são as fontes completas correspondentes dos instaladores. Para reproduzir esta distribuição, utilize esses arquivos e seus checksums; os arquivos Source code gerados automaticamente pelo GitHub não substituem os pacotes de fontes correspondentes.

As versões anteriores permanecem disponíveis. Testes automatizados não equivalem a teste físico em todos os aparelhos e centrais Bluetooth. Configure/teste o Modo Carro com o veículo estacionado.
